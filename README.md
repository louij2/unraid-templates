# unraid-templates

Unraid Community Applications templates for a handful of self-built tools —
[claude-code](https://github.com/louij2/claude-code),
[ado-exporter](https://github.com/louij2/ado-exporter),
[cloud-billing-exporter](https://github.com/louij2/cloud-billing-exporter),
[semaphore-exporter](https://github.com/louij2/semaphore-exporter),
[patchmon-exporter](https://github.com/louij2/patchmon-exporter),
[docker-mcp](https://github.com/louij2/docker-mcp),
[filesystem-mcp](https://github.com/louij2/filesystem-mcp),
[hass-mcp](https://github.com/louij2/hass-mcp),
[tailscale-mcp](https://github.com/louij2/tailscale-mcp), and
[homelab-runbooks](https://github.com/louij2/homelab-runbooks) (a generic
MkDocs Material docs-site template — bring your own docs repo).

## Add this repo to your own Unraid

**Apps** tab → **Settings** (top right) → **Template repositories** → add:

    https://github.com/louij2/unraid-templates

Save, then these show up alongside everything else when you search **Apps**
on your server. Each app's own repo has the Dockerfile/source and a README
with full config details — start there for anything beyond what the
template's own field descriptions cover.
